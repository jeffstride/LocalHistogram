These instructions are to help you show a local webpage with the ability to display a histogram of student grades.  

**Steps:**   
1. Open an Anaconda Terminal window to this directory.  
2. Type in `python app.py`  
3. Open `https://127.0.0.1:5001` in a browser  
4. To stop, type `Ctrl+C` in the terminal  

**Notes:**  
This creates a `Flask` app that will generate an HTML page via script. If you won't have `Flask` available, you'll need to "pip install It has access to the `histogram_work.py` file that creates the plot. It then navigates to a page to show the locally generated plot.
